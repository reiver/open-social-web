Open Social Web

decentralized networks of interoperable social media platforms using open protocols

by Charles Iliya Krempeaux

The Open Social Web is made up of decentralized social media platforms that uses open protocols.

The Open Social Web includes:

  • the Fediverse (i.e., Loops, Mastodon, Misskey, PeerTube, Pixelfed, and others running ActivityPub et al),
  • the ATmosphere (i.e., Blacksky, Bluesky, and others running ATProto et al),
  • Nostr,
  • and others.

The main Open Social Web protocols are:

  • ActivityPub,
  • ATProto,
  • Nostr (protocol),
  • Secure Scuttlebutt (protocol),
  • and others.

To understand the Open Social Web it helps to understand the Social Web. And, to understand the Social Web it helps to understand the Web. So, let's look at each of them.

Web

The Web, short for World Wide Web, traditionally is an interconnected system of public documents written in HTML, called web-pages, served from servers, called web-servers, that communicate using HTTP. Traditionally, most people access the World Wide Web via an application called a web-browser.

Nowadays, in addition to the traditional pattern, many people access the World Wide Web via bespoke applications that connect to web-servers that serve JSON, XML, CBOR (rather than HTML).

The original technologies used on the World Wide Web are: HTML, and HTTP.

Later the technologies supported on the World Wide Web expanded to include: URL, XBM, GIF, JPEG, JavaScript, CSS, JavaScript, Java Applets, Macromedia Shockwave Flash, DOM, XML, RSS, XMLHttpRequest (AJAX), SVG, JSON, Canvas, Geolocation, HTML5, WebSockets, WebRTC, WebAssembly (WASM), and others.

The core technology of the World Wide Web is HTTP (rather than HTML).

Social Web

The Social Web is an social version of the Web.

Open Social Web

The Open Social Web is an open version of the Social Web.

The Open Social Web:

  • uses open protocols
  • software is open-source
  • has open governance
  • has open access
  • has open infrastructure
