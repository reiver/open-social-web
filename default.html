Open Social Web

decentralized networks of interoperable social media platforms using open protocols

by Charles Iliya Krempeaux

The Open Social Web is made up of an decentralized social media platform that uses open protocols.

The main Open Social Web protocols includes things protocols such as: ActivityPub, ATProto, Nostr (protocol), Secure Scuttlebutt (protocol), and others.

To understand the Open Social Web it helps to understand the Social Web. And, to understand the Social Web it helps to understand the Web. So, let's look at each of them.

Web

The Web, short for World Wide Web, traditionally is an interconnected system of public documents written in HTML, called web-pages, served from servers, called web-servers, that communicate using HTTP. Traditionally, most people access the World Wide Web via an application called a web-browser.

Nowadays, in addition to the traditional pattern, many people access the World Wide Web via bespoke applications that connect to web-servers that serve JSON, XML, CBOR (rather than HTML).

The original technologies used on the World Wide Web are: HTML, and HTTP.

Later the technologies supported on the World Wide Web expanded to include: GIF

The core technology of the World Wide Web is HTTP (rather than HTML).
