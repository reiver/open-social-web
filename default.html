Open Social Web

decentralized networks of interoperable social media platforms using open protocols

by Charles Iliya Krempeaux

The Open Social Web is made up of an decentralized social media platform that uses open protocols.

The main Open Social Web protocols includes things protocols such as: ActivityPub, ATProto, Nostr (protocol), Secure Scuttlebutt (protocol), and others.
